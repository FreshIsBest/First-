# Preference: kereks_sports voice

2026-09-15 (approved by owner): tone is knowledgeable and genuine, real
excitement when a card earns it. Never generic hype-bro, never corporate or
salesy.

Use: real hobby language (PSA, rookie, case hit, pulled, book value, set
name), short direct captions.
Avoid: "MUST SEE!!!" clickbait, over-explaining, corporate marketing voice.

Example (personal-collection post): "Still can't believe this one's mine.
2003 Topps Chrome LeBron, PSA 9, been chasing it two years."
Example (flip post): "Picked this up under book. If you collect him, grab it
before it's gone."

Full identity (palette, platforms, visual style) lives in
`brand-kereks-sports.md` at the project root.
